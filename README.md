# SEIF ID STUDIO

استوديو تجهيز صور الهوية والجواز للطباعة، بواجهة عربية وألوان بيضاء وزرقاء.

## تشغيل نسخة الويب

افتح `index.html` أو انشر المستودع عبر GitHub Pages من Settings → Pages → Deploy from a branch → main / root.

## المزايا الحالية

- رفع صورة من الجهاز أو السحب والإفلات.
- مقاسات شائعة ومقاس مخصص بالملليمتر.
- أحجام ورق 10×15 وA4 وA5 و13×18 سم.
- توزيع نسخ تلقائي مع حدود قص.
- تصدير JPG وPNG بأبعاد محسوبة وفق DPI المختار.
- الطباعة أو الحفظ PDF من نافذة الطباعة.
- PWA وتخزين مؤقت للاستخدام دون اتصال بعد أول تحميل.
- معالجة الصور داخل المتصفح دون رفعها إلى خادم.

## Windows

يتطلب Node.js. نفّذ `npm install` ثم `npm run build:win`. ينتج المثبّت داخل مجلد `dist`.

## Android

يتطلب Android Studio وAndroid SDK. نفّذ `npm install` ثم `npx cap add android` (مرة واحدة)، وبعدها `npm run build:android` ثم افتح مشروع Android في Android Studio لبناء APK.

## ملاحظات الدقة

يُنشأ ملف الصورة بالبكسلات المحسوبة من الملليمتر وDPI. عند الطباعة اختر Actual size / 100% وأوقف Fit to page. حدود القص ظاهرة باللون الأحمر. تغيير لون خلفية الصورة هنا يلوّن مساحة الصورة فقط ولا يزيل الخلفية الأصلية تلقائياً؛ ميزة إزالة الخلفية وقواعد صور الوثائق الرسمية ستضاف في مرحلة لاحقة.
